= Pod placement
:description: Pod placement for Apache NiFi, covering the default affinities and placement next to OPA when OPA authorization is configured.

You can configure the Pod placement of the NiFi pods as described in xref:concepts:operations/pod_placement.adoc[].

The default affinities created by the operator are:

1. Distribute all the NiFi Pods (weight 70)
2. If OPA authorization is configured: co-locate the NiFi Pods with the OPA Pods (weight 50)
